## 四、作品技术摘要（供填表）

- 作品名称：赤星前哨 · 火星科研站
- 建模方式：CadQuery 参数化建模（1823 行）+ Blender 高模精修
- 模型规模：210 个物体、6 个功能分区、GLB 69 MB
- 核心参数：居住环 R=33.2 m、环管 Ø14.8 m、自转 3.20 rpm、环向应力 0.97 MPa
- 物理校核：人工重力、环向应力、薄壁屈曲、地基承载、尘暴抗倾覆 五项
- 质检：29 项自动化检查（几何 / 变换 / 落地 / 材质 / 命名 / 渲染 / 自相交 / UV / 拓扑）
