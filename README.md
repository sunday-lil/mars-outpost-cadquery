# 赤星前哨 · 火星科研站 (Mars Research Outpost)

基于 **CadQuery** 的参数化三维建模作品（探秘火星逐梦太空 · 智能算法编程类 · 三维设计项目）。

以 2030 年代火星科考前哨站为蓝图，按**功能分区**构建有机连通的综合基地：核心科研区、能源区、通信区、发射区、探测区、环境监测区，连接道路贯穿各区域。


## 结构与物理（v3，u = 3.125）

| 项目 | 数值 | 说明 |
|---|---|---|
| 全站单位 | **u = 3.125**（1 mm = 0.625 m） | 尺寸/位置/间距统一放大，相对方位不变 |
| 居住环 | 外径 81.2 m，环心半径 **R = 33.2 m**，环管 Ø14.8 m | 实测（包围盒 − 管径） |
| 自转速度 | ω = √(a/R) = **3.20 rpm** | 环缘 a = ω²R = 3.72 m/s²（1 g 火星） |
| 环向应力 | σ = ρaR = **0.97 MPa** | Q355 屈服 355 MPa → SF 373（强度非控制项） |
| 屈曲 | σ_cr = 0.6Et/R | 60 mm 壁板：σ_cr = 232 MPa ≫ 0.95 MPa ✓ |
| 甲板拉力 | T = pR = **1.17 MN** | 3 kPa × 12 m 环宽 |
| 地基 | 总重 ≈ 28 MN，需 350 m² | 4 座垫板实给 1960 m²，SF 5.6 |
| 风载 | 尘暴 0.4 kPa，倾覆 24 MN·m | 抗倾覆 700 MN·m，SF 29 |
| 场地 | **1200 m** 见方地形，**半径 420 m 场平垫** | 所有物体落在垫上，陷地 0 个 |

完整计算见 [exports/结构仿真说明.md](exports/结构仿真说明.md)。

## 元素整合说明

原本散乱的元素已整理为有机整体：

- **天线合并**：大口径抛物面天线（阶段二）直接集成到通信塔顶，替代原来重复的小口径天线——一座塔、一套天线
- **推进器合并**：离子推进器散热格栅 + 收敛-扩张喷管（阶段一）作为火箭动力段集成到发射区，替代重复的化学火箭喷管——一套推进系统
- **新增道路**：连接道路贯穿居住环→实验舱→通信塔→发射区→气象站→能源区→火星车，从散点布局升级为有机连通基地
- **气象站增强**：从单一风速计升级为综合环境监测平台（中心主桅杆 + 斯蒂文森百叶箱，温湿压探头收在箱内）

## 核心算法

- 极坐标放置、三角函数定向斜杆、向心加速度 a=ω²R 的旋转居住环、椭圆参数方程整流罩
- 抛物线 `z = r²/(4f)` 微积分推导 + 旋转成抛物面天线
- 多截面放样 `loft`：两圆截面生成焦点馈源喇叭（内置 Ø8×12mm 谐振腔）与根粗端细的锥形支撑臂
- 斯蒂芬-玻尔兹曼热辐射定律 → 百叶窗散热格栅设计
- CadQuery 批量布尔差集（`cut`）+ Z-Fighting 贯通容差修复
- 随机数撒布岩石（固定种子可复现）+ 禁布区防穿模
- 太阳能板倾角 = 90° − 太阳高度角（自动对日）
- 自研 glTF 2.0 GLB 导出器（仅用 `json` + `struct` 标准库），含 PBR 材质 + 平滑法线 + 太阳光照
- **程序化纹理贴图**：14 种程序化纹理（火星地表/金属面板/太阳能板/火箭壳体/抛物面反射器/车辙路径/火星车漆/车轮胎面/机械臂拉丝/居住环蒙皮/玻璃/金边框/热变色喷管/信标灯罩）+ 4 张粗糙度贴图，26 种材质全部带 `baseColorTexture`；纯标准库 `zlib` PNG 编码嵌入 GLB，另加按高度混入火星尘的顶点色

## 运行

```bash
python mars_outpost.py
```

输出（`exports/` 目录）：

| 文件 | 说明 |
|---|---|
| `mars_outpost.step` | 带彩色分层的工程交换文件 |
| `mars_outpost.glb` | Blender 即开即用，含 PBR 材质（自研 glTF 2.0 导出器，仅用标准库） |
| `mars_outpost.stl` | 整体网格 |
| `parabolic_dish_reflector.stl` | 高精度抛物面反射器（深空通信） |
| `view_iso/top/front.svg` | 三视角工程线框图 |

运行时终端输出 X 波段天线增益核算结果（dBi）。

**在线预览**：在项目根目录运行 `python -m http.server`，浏览器打开 `viewer.html`，即可实时旋转查看 `exports/mars_outpost.glb`（含 PBR 材质、环境反射与程序化纹理）。

全站参数化：修改脚本顶部【参数区】常数（如 `SUN_ELEV` 太阳高度角、`DISH_F` 抛物面焦距、`GRILL_SLOTS` 散热槽数），模型自动重建。

## 参数区关键常量

| 参数 | 默认值 | 说明 |
|---|---|---|
| `GRILL_SLOTS` | 24 | 散热格栅槽数 |
| `GRILL_TILT` | 15° | 百叶窗倾斜角（热辐射优化） |
| `GRILL_TOLERANCE` | 1mm | Z-Fighting 贯通容差 |
| `DISH_F` | 45mm | 抛物面焦距 |
| `DISH_D` | 120mm | 天线口径直径 |
| `DISH_WALL` | 2mm | 反射体壁厚 |
| `X_BAND_FREQ` | 8.4 GHz | X 波段中心频率 |
