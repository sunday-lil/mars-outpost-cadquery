# 赤星前哨 · 火星科研站 (Mars Research Outpost)

基于 **CadQuery** 的参数化三维建模作品（探秘火星逐梦太空 · 智能算法编程类 · 三维设计项目）。

以 2030 年代火星科考前哨站为蓝图，构建"一站多器"综合场景：主居住穹顶、科研实验舱、加压廊道、太阳能翼阵、深空通讯塔、六轮火星车、返回火箭着陆平台、气象观测站。

## 项目阶段

### 阶段一：基础场景 + 离子推进器动力总成

- **基础场景**：穹顶、实验舱、廊道、太阳能翼阵、通讯塔、火星车、火箭着陆平台、气象站
- **离子推进器动力总成**（大通关）：
  - 24 槽全向辐射散热格栅，倾斜 15° 百叶窗式设计
  - 依据 **斯蒂芬-玻尔兹曼热辐射定律**（`P = ε·σ·A·T⁴`）计算有效散热辐射表面积倍增效应
  - CadQuery **批量布尔差集**（`cut`）高效算法：24 组刀具体圆周阵列
  - **Z-Fighting 修复**：刀具体两端预留 1mm 贯通容差，杜绝微小坏面与缝隙，100% 水密交付
  - 收敛-扩张喷管旋转体 + 推进剂储箱段箍 + 接口法兰

### 阶段二：深空通信系统

- **旋转抛物面高增益天线**：
  - 严谨推导抛物面几何方程 `z = r²/(4f)`，证明平行射入电磁波 100% 汇聚于焦点
  - `ParabolicDishGenerator` 几何生成器：微积分点集离散采样算法生成壁厚 2mm 反射体截面
  - 围绕 Y 轴 360° 旋转拉伸，外边缘并集构建刚性加固法兰圈
  - X 波段（8.4 GHz）深空通信链路增益核算（dBi）
  - 导出高精度抛物面反射器 STL（`tolerance=0.1`）

## 核心算法

- 极坐标放置、三角函数定向斜杆、海伦公式求弧半径
- 抛物线 `z = r²/(4f)` 微积分推导 + 旋转成抛物面天线
- 斯蒂芬-玻尔兹曼热辐射定律 → 百叶窗散热格栅设计
- CadQuery 批量布尔差集（`cut`）+ Z-Fighting 贯通容差修复
- 随机数撒布岩石（固定种子可复现）+ 禁布区防穿模
- 太阳能板倾角 = 90° − 太阳高度角（自动对日）
- 自研 glTF 2.0 GLB 导出器（仅用 `json` + `struct` 标准库），含 PBR 材质 + 平滑法线 + 太阳光照

## 运行

```bash
python mars_outpost.py
```

输出（`exports/` 目录）：

| 文件 | 说明 |
|---|---|
| `mars_outpost.step` | 带彩色分层的工程交换文件 |
| `mars_outpost.glb` | Blender 即开即用，含 PBR 材质（自研 glTF 2.0 导出器，仅用标准库） |
| `mars_outpost.stl` | 整体网格 |
| `parabolic_dish_reflector.stl` | 高精度抛物面反射器（阶段二深空通信） |
| `view_iso/top/front.svg` | 三视角工程线框图 |

运行时终端输出 X 波段天线增益核算结果（dBi）。

全站参数化：修改脚本顶部【参数区】常数（如 `SUN_ELEV` 太阳高度角、`DISH_F` 抛物面焦距、`GRILL_SLOTS` 散热槽数），模型自动重建。

## 参数区关键常量

| 参数 | 默认值 | 说明 |
|---|---|---|
| `GRILL_SLOTS` | 24 | 散热格栅槽数 |
| `GRILL_TILT` | 15° | 百叶窗倾斜角（热辐射优化） |
| `GRILL_TOLERANCE` | 1mm | Z-Fighting 贯通容差 |
| `DISH_F` | 45mm | 抛物面焦距 |
| `DISH_APERTURE` | 120mm | 天线口径直径 |
| `DISH_WALL` | 2mm | 反射体壁厚 |
| `X_BAND_FREQ` | 8.4 GHz | X 波段中心频率 |
