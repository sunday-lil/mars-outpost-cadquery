# 赤星前哨 · 火星科研站 (Mars Research Outpost)

基于 **CadQuery** 的参数化三维建模作品（探秘火星逐梦太空 · 智能算法编程类 · 三维设计项目）。

以 2030 年代火星科考前哨站为蓝图，按**功能分区**构建有机连通的综合基地：核心科研区、能源区、通信区、发射区、探测区、环境监测区，连接道路贯穿各区域。

## 场景分区与元素

| 分区 | 元素 | 说明 |
|---|---|---|
| **核心科研区** | 居住穹顶 + 科研实验舱 + 加压廊道 | 椭圆参数方程旋转穹顶、圆柱机身+半球封头、样条扫掠廊道 |
| **能源区** | 太阳能翼阵 | 倾角 = 90° − 太阳高度角（自动对日），银框+蓝片阵列 |
| **通信区** | 深空通信塔 + 大口径抛物面天线 | 三柱桁架 + 24 槽散热格栅 + 收敛-扩张喷管（阶段一集成） |
| **发射区** | 着陆平台 + 返回火箭 + 离子推进器动力段 | 抛物面 z=r²/(4f) 微积分推导 + 法兰圈（阶段二集成） |
| **探测区** | 六轮火星车 | 摇臂悬架 + 12 齿抓地轮 + 双目桅杆 + 机械臂 |
| **环境监测区** | 综合气象站 | 三杯风速计 + 百叶箱 + 温湿压传感器阵列 |
| **连接网络** | 压痕路径 | 地表车辙道路连接所有分区，形成有机整体 |

## 元素整合说明

原本散乱的元素已整理为有机整体：

- **天线合并**：大口径抛物面天线（阶段二）直接集成到通信塔顶，替代原来重复的小口径天线——一座塔、一套天线
- **推进器合并**：离子推进器散热格栅 + 收敛-扩张喷管（阶段一）作为火箭动力段集成到发射区，替代重复的化学火箭喷管——一套推进系统
- **新增道路**：连接道路贯穿穹顶→实验舱→通信塔→发射区→气象站→能源区→火星车，从散点布局升级为有机连通基地
- **气象站增强**：从单一风速计升级为综合环境监测平台（温度/湿度/气压分层传感器）

## 核心算法

- 极坐标放置、三角函数定向斜杆、海伦公式求弧半径
- 抛物线 `z = r²/(4f)` 微积分推导 + 旋转成抛物面天线
- 斯蒂芬-玻尔兹曼热辐射定律 → 百叶窗散热格栅设计
- CadQuery 批量布尔差集（`cut`）+ Z-Fighting 贯通容差修复
- 随机数撒布岩石（固定种子可复现）+ 禁布区防穿模
- 太阳能板倾角 = 90° − 太阳高度角（自动对日）
- 自研 glTF 2.0 GLB 导出器（仅用 `json` + `struct` 标准库），含 PBR 材质 + 平滑法线 + 太阳光照
- **程序化纹理贴图**：6 种 fBm 噪声纹理（火星地表/金属面板/太阳能板/火箭壳体/抛物面反射器/车辙路径），纯标准库 `zlib` PNG 编码嵌入 GLB 作为 `baseColorTexture`，平面投影 UV 自动生成

## 运行

```bash
python mars_outpost.py
```

输出（`exports/` 目录）：

| 文件 | 说明 |
|---|---|
| `mars_outpost.step` | 带彩色分层的工程交换文件 |
| `mars_outpost.glb` | Blender 即开即用，含 PBR 材质（自研 glTF 2.0 导出器，仅用标准库） |
| `mars_outpost.stl` | 整体网格 |
| `parabolic_dish_reflector.stl` | 高精度抛物面反射器（深空通信） |
| `view_iso/top/front.svg` | 三视角工程线框图 |

运行时终端输出 X 波段天线增益核算结果（dBi）。

全站参数化：修改脚本顶部【参数区】常数（如 `SUN_ELEV` 太阳高度角、`DISH_F` 抛物面焦距、`GRILL_SLOTS` 散热槽数），模型自动重建。

## 参数区关键常量

| 参数 | 默认值 | 说明 |
|---|---|---|
| `GRILL_SLOTS` | 24 | 散热格栅槽数 |
| `GRILL_TILT` | 15° | 百叶窗倾斜角（热辐射优化） |
| `GRILL_TOLERANCE` | 1mm | Z-Fighting 贯通容差 |
| `DISH_F` | 45mm | 抛物面焦距 |
| `DISH_D` | 120mm | 天线口径直径 |
| `DISH_WALL` | 2mm | 反射体壁厚 |
| `X_BAND_FREQ` | 8.4 GHz | X 波段中心频率 |
